# 院の連絡帳

見たら印がつく、スタッフどうしの連絡帳です。
施術所の院長・スタッフが、スマホのブラウザで使います。

- 今日のボード（見たら「確認しました」）・大事な連絡・ひとこと返信
- 今日いる人（出勤・遅れ・休み）
- 申し送り・訪問の動き・開院前／閉院後の点検・備品
- 一人ひとりの暗証番号、数店舗（全店まとめ・店長）
- 院の帳：予定・決まり（読みました）・新人の練習・ありがとうカード・探す
- よく使う連絡（定型文）
- ホーム画面に置ける（アプリのように開ける）・スマホへのお知らせ
- 控え（表のファイルで保存）

記録は、置いた院のCloudflareのアカウントに置かれます。作った人のところには届きません。

## 置く

スマホでも置けます。下のボタンを押して、画面の案内に沿って進めてください。

**図で見る置き方：** https://staff-board.bonojam.workers.dev/tebiki

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/yukawa-care/inno-renrakucho)

途中で **院長の合言葉**（INCHO_PASSCODE）と **スタッフの合言葉**（STAFF_PASSCODE）を聞かれます。それぞれ6文字以上で、別のものにしてください。紙に控えておきます。

置けたら、表示されたアドレスを開き、院長の合言葉で入って「はじめの設定」で院の名前とスタッフの名前を入れます。

くわしくは「置き方_スマホ.md」と「使い方.md」を見てください。

## パソコンで置くとき

このページの緑色の「Code」ボタン →「Download ZIP」でダウンロードし、「置き方.md」の手順で進めます。

## まず触ってみる

お試し用のアドレスで、合言葉なしで触れます（実際の院の記録は書かないでください）。

https://staff-board.bonojam.workers.dev

## 気をつけること

- 通ってこられる方の名前や体の状態を書くかどうかは、院の決まりで決めてください。法令に関わるところは、所管の保健所や専門家に確かめてください
- 合言葉と暗証番号は人に教えないでください
- スマホへのお知らせを勤務時間外にどう扱うかは、院で決めてください（働き方の決まりは専門家に確かめてください）
- 使い方の問い合わせは受けていません。マニュアルと図解を見て、それでも進めないときは画面を写して Claude などの AI に見せて聞いてください
